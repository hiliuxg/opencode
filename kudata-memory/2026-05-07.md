## 修改的文件详情

### MCP 工具精简与权限

- `kudata-memory/kudata-mcp.ts` 移除 `send_wechat_message`、`render_chart`、`get_file_link`、`manage_schedule` 四个工具，代码从 ~530 行精简到 ~150 行。
- `kudata-mcp_sql_query_result` 重构 SQL 查询执行链路：skill 模式下先校验用户权限，通过后调用 skill 接口；skill 接口返回权限拒绝或业务账号为空时自动 fallback 到 personal 接口；无 skill 则直接走 personal 接口。
- 新增 `fetchUserSkills` 调用和 admin 白名单机制，避免每次查询都校验已授权的管理员用户。

### Admin cron 并发与超时

- `packages/admin/src/cron/executor.ts` 默认并发数从 5 提高到 30，允许同时运行更多定时任务。
- 移除 opencode 调用失败后的重试逻辑（maxRetries 从 3 改为 0），避免失败的 job 重复排队。
- opencode 请求超时从按 job 配置的 `timeout_seconds`（默认 5 分钟）统一改为 60 分钟，确保长时间运行的任务不会被中断。
- `packages/admin/src/cron/executor.test.ts` 新增测试：默认并发 30 时第 31 个 job 排队等待；openode 调用使用 60 分钟超时。

### 会话侧栏缓存与去重

- `packages/app/src/pages/layout/conversation-sidebar.tsx` 引入全局缓存层（cats、totals、pages 三张 Map），避免相同参数重复请求。
- 新增 gate 机制（countgate/countchange、pagegate/pagechange）确保同一 key 不会并发发起多次 API 调用；请求成功则标记完成不再重复，失败后允许重试。
- 新增 fingerprint 签名机制，基于 session 的 directory、id、catalogID、archived、pinned 等关键字段生成变更指纹，只有结构性变化才触发重新请求。
- 新增 synced 检查，等所有可见工作区的 session 同步完成后才发起 catalog 请求，避免半加载状态下的无效调用。
- 新增 patchPages 乐观更新：pin、重命名等单条操作不再整页刷新，直接就地替换缓存中对应 session。
- 操作后通过 stale() 统一失效缓存，替代逐个 `fetchArchived` / `fetchSessions` / `fetchCounts` 调用。
- 新增 inst 实例计数和全链路 trace 日志，记录 mount/cleanup/请求启停/gate 判断/缓存命中等关键节点，便于排查重复渲染和重复请求。
- `packages/app/src/pages/layout/helpers.ts` 新增 `remember`、`fingerprint`、`synced`、`gates`、`gate`、`done`、`reset`、`changed` 等工具函数。
- `packages/app/src/pages/layout/conversation-sidebar.test.ts` 新增 fingerprint 变更检测、synced 同步等待、gate 去重/重试/重置、changed 就绪门控 4 组共 15 个测试用例。

### App 布局媒体查询

- `packages/app/src/pages/layout.tsx` 引入 `createMediaQuery("(min-width: 1280px)")`，桌面布局下才渲染 desktop 侧栏、移动端布局下才显示 mobile sidebar，peek sidebar 也只在桌面端展示，避免移动端渲染无用 DOM。

### SQL 工具信息展示

- `packages/ui/src/components/tool-sql-info.ts` 新增 `sqlinfo` 和 `sqlerr` 两个工具函数。
- `sqlinfo` 从工具输入中提取 engine、cluster 和 skill_name，组装为 `engine · cluster · skill` 格式的副标题。
- `sqlerr` 优先取 `parsed.message` 或 `parsed.data.result_msg`，均为空时 fallback 到原始输出字符串。
- `packages/ui/src/components/message-part.tsx` 的 `getToolInfo` 和 `ToolRegistry` 中 SQL 查询工具改用 `sqlinfo` 生成 subtitle；`SqlQueryRenderer` 的错误展示从 `<div>` 改为 `<pre>` 并保留空白符与换行。
- `packages/ui/src/components/message-part.test.ts` 新增 sqlinfo 和 sqlerr 的测试用例。

## 本次变更的主题

1. **MCP 工具精简**：移除未使用或已被其他工具替代的函数，只保留核心 SQL 查询能力，并补齐 skill 权限校验与 fallback。
2. **cron 执行更可靠**：提高并发上限、移除失败重试、拉长超时时间，避免长时间查询被中断或重复调度。
3. **侧栏请求大幅减少**：通过全局缓存、gate 去重和 fingerprint 变更检测，相同视图不再重复发请求，单条操作也只做就地更新。
4. **移动端布局隔离**：媒体查询确保侧栏组件在对应端才渲染，减少 DOM 开销。
5. **SQL 工具 UI 信息更丰富**：展示引擎、集群和技能名，错误信息保留原始格式。
