## 修改的文件详情

### Docker 与部署文档

- `.gitignore` 新增 `docker/*` 忽略规则，并保留 `docker/entrypoint.sh` 可提交；`docker/cc-connect/` 内二进制和配置继续作为本地构建素材，不纳入 git。
- `Dockerfile` 从 amd64 opencode 产物构建镜像，加入 `cc-connect` 二进制、配置和入口脚本，默认通过 `entrypoint.sh` 启动。
- `docker/entrypoint.sh` 新增容器入口：默认 `both` 模式先启动 opencode server，健康检查通过后再启动 `cc-connect`，并监控两个进程生命周期。
- `DEVELOPMENT.md` 收缩为当前部署片段，镜像版本更新到 `opencode-v1313-05036355`，并补充 cc-connect Linux binary 打包到 Docker build context 的步骤。

### App 侧会话与输入体验

- `packages/app/src/pages/layout/helpers.ts` 新增 `archivedList`，用于本地更新归档缓存并按更新时间排序；新增 `movable` 判断归档分类下不展示移动入口。
- `packages/app/src/pages/layout/conversation-sidebar.tsx` 归档会话后立即同步本地归档列表；归档分类下隐藏“移动”菜单项。
- `packages/app/src/pages/layout/conversation-sidebar.test.ts` 覆盖归档缓存新增、替换和移动入口显示逻辑。
- `packages/app/src/context/settings.tsx` 默认开启 reasoning summaries。
- `packages/app/src/i18n/zh.ts` 将技能选择弹窗标题从“选择技能”简化为“技能”。
- `packages/app/src/components/prompt-input.tsx` 临时隐藏模型 variant 选择器和 shield 按钮相关 UI。

### UI MCP 文件链接展示

- `packages/ui/src/components/tool-file-link.ts` 新增 `filelink`，根据 MCP 输入里的 `type`、`filepath`、`filePath` 生成工具标题、图标和副标题。
- `packages/ui/src/components/message-part.tsx` 支持 `kudata-mcp_get_file_link`，展示共享链接或下载链接的工具信息，并注册对应工具渲染。
- `packages/ui/src/components/message-part.test.ts` 覆盖 `filepath` 优先级和 `filePath` fallback。
- `packages/ui/src/i18n/en.ts`、`zh.ts`、`zht.ts` 新增获取文件链接、共享链接、下载链接文案。

### opencode bash 工具

- `packages/opencode/src/tool/bash.ts` 在 bash 工具环境变量中注入 `OPENCODE_CURRENT_DIR`，值来自当前 `Instance.directory`。
- `packages/opencode/test/tool/bash.test.ts` 增加测试，验证子进程能读取 `OPENCODE_CURRENT_DIR`。
- `packages/opencode/src/session/prompt.ts` 移除模型返回空内容时注入 token 额度错误的判断逻辑，保留原有 structured output 检查。

### 其他文件

- `mycodex.md` 新增一份通用 agent 编码行为指南，强调先澄清、保持简单、外科式改动和目标驱动验证。
