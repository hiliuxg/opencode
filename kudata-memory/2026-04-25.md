# 2026-04-25 Git 修改记录

## 新增功能

### 1. 会话分类（Session Catalog）
- 新增 `SessionCatalogID` 类型，ID 前缀为 `cat`
- 数据库新增 `session_catalog` 表，字段：id, project_id, directory, key, name, icon, sort, timestamps
  - key 支持：temp（临时会话）、analysis（专项分析）、notes（学习笔记）、archived（已归档）
  - 系统预设分类不可删除
- `session` 表新增 `catalog_id` 外键（级联置空）和 `time_pinned` 字段
- Session 模块新增 `Catalog` 命名空间：
  - `Catalog.list(directory)` — 列出分类
  - `Catalog.create({ directory, name, icon?, sort? })` — 创建分类
  - `Catalog.update({ catalogID, name?, icon?, sort? })` — 更新分类
  - `Catalog.remove(catalogID)` — 删除分类（系统分类禁止删除，删除后会话 catalog_id 置空）
- 新增 `SystemCatalogError` 错误类型
- Server 路由新增 `/session/catalog` 相关 REST API（GET / POST / PATCH / DELETE）
- 错误处理中间件和 server 对 `SystemCatalogError` 返回 400

### 2. 会话置顶（Pin）
- `session` 表新增 `time_pinned` 字段
- Session 模块新增 `setPinned({ sessionID, pinned })` 方法
- `archiveSession` 支持传入 `catalogID` 和 `pinned` 参数
- UI 新增 `pin` 图标

### 3. 前端 ConversationSidebar 组件
- 新增 `packages/app/src/pages/layout/conversation-sidebar.tsx`
- `layout.tsx` 中侧边栏面板替换为 `ConversationSidebar`，支持：
  - 分类展示会话列表
  - 置顶会话展示
  - 搜索会话
  - 会话移动分类、置顶/取消置顶、归档/取消归档、重命名
- `peekProject` 和 `currentProject` 都使用 ConversationSidebar

### 4. FileTree 自动展开当前文件
- `dirsToExpand` 新增 `active` 参数，自动计算活动文件所在目录并展开
- `session-side-panel.tsx` 中向 FileTree 传入当前活动文件路径 `active={path()}`
- `session.tsx` 中文件树 tab 自动选中逻辑优化（移除 `active !== "review"` 限制）
