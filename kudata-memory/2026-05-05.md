## 修改的文件详情

### 会话分类侧栏分页与计数

- `packages/app/src/pages/layout/conversation-sidebar.tsx` 将会话列表从本地 session store 过滤切换为调用服务端分类分页接口。
- 侧栏按当前工作区过滤 catalog，并为多工作区场景按系统 catalog key 映射到各自目录下的 catalog。
- 新增每个目录的分页状态、加载状态、搜索 key 和追加加载逻辑，置顶会话与普通会话分开返回后再统一展示。
- 分类计数改为调用服务端 counts 接口，避免依赖前端当前已加载 session 数量。
- pin、归档、删除、重命名等会改变列表的操作完成后重新刷新分页数据。
- `packages/app/src/pages/layout/helpers.ts` 新增 `catalogForDirectory`，并让 `catalogs` 支持按目录过滤。

### 服务端分类会话 API

- `packages/opencode/src/session/index.ts` 新增 `Session.Catalog.counts`，按 temp、archived 和自定义 catalog 的语义统计根会话数量。
- `packages/opencode/src/session/index.ts` 新增 `Session.Catalog.sessions`，返回置顶会话、未置顶分页列表、总数和下一页 cursor。
- 服务端分页按照 `time_updated` 和 session id 倒序排序，cursor 使用更新时间和 id 组合，避免同一更新时间下分页重复或跳过。
- `packages/opencode/src/server/routes/session.ts` 新增 `GET /session/catalog/counts` 和 `GET /session/catalog/:catalogID/sessions`。
- `packages/opencode/src/server/server.ts` 将 `Session.BusyError` 映射为 400 响应，避免忙碌状态落入通用 500 错误。
- `packages/opencode/test/server/session-catalog-sessions.test.ts` 新增端到端路由测试，覆盖置顶分离、cursor 分页、temp catalog、archived catalog 和 counts 语义。

## 本次变更的主题

1. **会话侧栏改为服务端分页**：列表、搜索、加载更多都通过 catalog sessions API 获取，减少前端对全量 session store 的依赖。
2. **分类数量由服务端统一计算**：counts API 按系统 catalog 和自定义 catalog 的真实语义统计根会话。
3. **多工作区 catalog 更稳**：前端不会把一个目录下的自定义 catalog 误用到另一个目录。
4. **SDK 与测试补齐**：新增接口同步到 JS SDK，并用服务端路由测试覆盖分页和计数行为。
