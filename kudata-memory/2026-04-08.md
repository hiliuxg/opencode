### packages/opencode/src/server/server.ts

**新增技能检查更新 API**

- 新增 GET `/skill/check-updates` 路由
- 遍历所有技能，按 Git 仓库根目录去重（多个技能可能在同一仓库）
- 对每个仓库执行 `git fetch origin`，获取远程更新
- 支持 HTTP(S) 远程仓库的自动认证注入（使用 `OPENCODE_SKILL_MARKET_TOKEN`）
- 计算本地分支落后远程 commits 数：`git rev-list HEAD..origin/{branch} --count`
- 返回格式：`{ updates: { skillName: { behind: number, branch: string } } }`
- 操作完成后恢复原远程 URL
